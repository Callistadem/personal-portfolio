Project Overview

BookBook is a comprehensive full-stack web application designed for readers to track their reading habits and manage their personal libraries. The platform combines the functionality of a virtual library with reading analytics to help users stay motivated and organized in their reading journey.

Key Features

  • User authentication system with secure login and registration
  • Personal virtual library to catalog books by status (reading, completed, want to read)
  • Reading habit tracker
  • Book search integration to easily add new titles to your library

Technical Implementation

Frontend Architecture

Built with React.js using functional components and hooks for state management. Implemented responsive design principles to ensure seamless experience across desktop and mobile devices. Created reusable component library for consistent UI/UX throughout the application.

Backend Development

Developed RESTful API using Node.js and Express framework. Implemented JWT authentication for secure user sessions.

Database Design

Utilized PostgreSQL to efficiently store user data, book information, and reading progress.

RedTalk

Role Frontend Developer
Team Size 4 Members
Client McGill University

Project Overview

RedTalk is an internal communication web application designed specifically for McGill University staff and students. The goal was to create a Slack/Discord alternative that could integrate with McGill's existing systems while providing familiar messaging and collaboration features. Our team of 4 developed this application to improve campus communication and reduce reliance on external platforms.

Key Features

  • Real-time messaging with channels organized by departments, courses, and student groups
  • Direct messaging for one-on-one conversations
  • File sharing capabilities for documents and images
  • User authentication integrated with McGill's system
  • Search functionality to find messages, files, and users
  • Notification system for mentions and direct messages
  • Channel creation and management for administrators
  • User profiles showing department affiliation and role (student/staff/faculty)

My Contributions

UI/UX Design

Collaborated on designing the user interface in Figma, focusing on creating an intuitive layout similar to familiar chat applications while adding McGill-specific branding. Designed the channel sidebar, message view, and user profile sections.

Frontend Implementation

Built the frontend using React.js, implementing components for the chat interface, channel list, message input, and user management. Focused on creating reusable components to maintain code quality and consistency.

API Integration

Worked closely with the backend team to integrate RESTful API endpoints. Implemented data fetching for messages, channels, and user information. Handled error states and loading indicators for better user experience.

State Management

Implemented complex state management to handle real-time message updates, channel switching, and user presence indicators. Ensured smooth transitions and responsive UI updates.
